## Запуск для обычных людей  
Устанавливаете python 3.11  
Скачиваете релиз чита  
Распаковываете в удобное вам место  
Открываете консоль от админа  
Вписываете:  
cd и путь до папки чита  
Далее в эту же консоль:  
```
pip install -r requirements.txt
```
Это установит все нужные нам зависимости  
В эту же консоль:  
```
pip install pyMeow
```
Это установит нам pyMeow (что в целом очевидно)  
Если pyMeow не устанавливается или чит не запускается, альтернатива:  
Заходите и скачиваете [pyMeow](https://github.com/qb-0/pyMeow/releases), закидываете не разорхивируя к читу, в консоль:  
```
pip install pyMeow-x.xx.xx.zip (подставьте название своего файла)
```
Несмотря на то, что я сохранил изначальную структуру и должна работать автоподгрузка оффсетов, но я настоятельно рекомендую скачать [cs2-dumper](https://github.com/a2x/cs2-dumper), закидываете его просто в папку к читу, запускаете кс2, далее во всё ту же консоль вводите:  
```
cs2-dumper -f json
```
Это создаст нам актуальные оффсеты, при любой обнове кс2:  
Удаляете папку "output", заново заходите через cd в папку чита, заново создаёте оффсеты  
И, наконец-то, запускаем чит, во всё ту же консоль:  
```
python main.py
```
При ошибках на любом из этапов:  
Открываете неиронку, скидываете ей оригинальный [cs2_neron_external](https://github.com/SadraKhorami/cs2_neron_external) и скидываете ей вывод консоли, там разберётесь  
Чтобы гарантированно закрыть чит, во всё ту же консоль (её нужно держать всегда открытой, чтобы чит работал):  
```
taskkill /F /IM python.exe
```
Это закроет весь питон

Использование читов полностью на вашей совести и я не могу ничего гарантированно утверждать, вак развивается и вас спокойно может забанить  
Но на моём опыте не забанило  
Опять же: это ничего не обозначает, мой единичный опыт ничего не доказывает, используйте на свой страх и риск, выложено в образовательных целях и тп и тд
